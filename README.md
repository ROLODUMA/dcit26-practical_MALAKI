# Team Directory App

A React Team Directory application created for a laboratory activity.

## Technologies

- React
- Vite
- React Router
- Tailwind CSS
- JavaScript

## Features

- Home page
- Users page
- User details page
- About page
- 404 page
- Search users
- Favorite users
- Dark/Light mode
- Loading state
- Error state
- Reusable components
- Dynamic document title
- React Router navigation
